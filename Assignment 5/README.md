# Assignment 5 - Chai & Co.

## Project Overview

Chai & Co. is a simple tea cafe landing page
created using HTML and CSS.

## Technologies Used

- HTML5
- CSS3

## Features

- Navigation Bar
- Hero Section
- About Section
- Chai Menu Cards
- Gallery
- Contact Form
- Footer

## Design Choices

- Cream background gives a warm look.
- Brown is used for the navbar and footer.
- Terracotta highlights the menu.
- Rounded cards make the website attractive.
- Box shadows give depth to the cards.
- Position and z-index are used in the hero section.
