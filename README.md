# Assignment 2 – The Ultimate Form

## Project Description
This project is a Job Application Form created using HTML5.

The form collects personal details, educational information, skills, and other application-related details.

## Features
- Personal Details Form
- Name, Email, Password and Phone Inputs
- Gender Selection using Radio Buttons
- Skills Selection using Checkboxes
- Course Selection using Dropdown
- City Suggestions using Datalist
- Date and Time Inputs
- Resume Upload
- Expected Stipend Range
- Favourite Colour Picker
- Textarea for Application Reason
- Submit and Reset Buttons
- HTML Form Validation

## Technologies Used
- HTML5
