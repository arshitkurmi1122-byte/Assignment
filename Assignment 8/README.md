# Assignment 8 – Responsive Audit

## About

This assignment focuses on making existing web pages responsive using CSS Media Queries.

## Pages Included

1. **gallery.html** – Responsive image gallery.
2. **product-grid.html** – Responsive product grid.
3. **dashboard.html** – Responsive dashboard layout.

## Concepts Used

- CSS Media Queries
- Responsive Design
- Tablet Breakpoint (768px)
- Mobile Breakpoint (480px)
- CSS Grid
- Flexible Images
- Overflow Control

## Screen Sizes Tested

- Desktop: 1200px
- Tablet: 768px
- Mobile: 375px

## Technologies Used

- HTML5
- CSS3

## Learning Outcome

Learned how to make existing websites responsive for desktop, tablet and mobile screens using CSS Media Queries.
