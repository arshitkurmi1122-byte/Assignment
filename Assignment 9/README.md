# Assignment 10 – Final Mini Project

## Campus Collective – Responsive Landing Page

### About Project

Campus Collective is a responsive student community landing page built using HTML and CSS. It provides information about learning, building projects, finding mentors and joining campus activities.

### Features

- Responsive navigation bar
- Hero section with Join Us button
- Six feature cards using CSS Grid
- Community gallery section
- Call-to-action section
- Footer with navigation links
- Mobile, tablet and desktop responsive design

### Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries
