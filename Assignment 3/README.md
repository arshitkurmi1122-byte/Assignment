# Assignment 3 – University Performance Dashboard

## Project Description

A University Student Performance Dashboard created using HTML5 and CSS3.

It displays academic records of 20 students from CSE and IT departments.

## Features

- Student academic performance table
- 20 student records and 10 columns
- Department and semester grouping
- Rowspan and Colspan
- Table header, body and footer
- Striped table rows
- Hover effects
- Responsive table layout
- CSS variables

## Technologies Used

- HTML5
- CSS3

## Files

- index.html – Table structure
- style.css – Table design
- README.md – Project documentation

## How to Run

1. Open the project folder in VS Code.
2. Open index.html.
3. Run using Live Server.

## Learning Outcomes

- HTML table elements
- Table grouping
- Rowspan and Colspan
- CSS variables
- Table styling
- Responsive design
