# Assignment 2 – The Ultimate Form

## Project Description
A Job Application Form created using HTML5.

## Features
- Personal Details
- Email and Password Inputs
- Phone Number and Portfolio URL
- Gender Selection
- Skills Selection
- Course Dropdown
- City Datalist
- Date and Time Inputs
- Resume Upload
- Stipend Range
- Colour Picker
- Textarea
- Submit and Reset Buttons
- Form Validation

## Technologies Used
- HTML5

## How to Run
1. Open the project folder in VS Code.
2. Open index.html.
3. Run using Live Server.

## Learning Outcomes
- HTML Forms
- Different Input Types
- Labels and Fieldsets
- Form Validation
- Select and Datalist
