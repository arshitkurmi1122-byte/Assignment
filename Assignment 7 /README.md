# Assignment 7 – CSS Grid Layout

## Objective

Learn two-dimensional layouts using CSS Grid.

## Technologies Used

- HTML5
- CSS3

## Projects Included

### 1. Photo Gallery (gallery.html)

- Created a photo gallery using CSS Grid.
- Added 9 images.
- Used 3-column layout.

### 2. Product Grid (product-grid.html)

- Created a product card layout.
- Added 6 product cards.
- Used auto-fit and minmax() for responsive columns.

### 3. Dashboard (dashboard.html)

- Created a simple dashboard layout.
- Added Header, Sidebar, Main Content and Footer.
- Used named grid areas.

## CSS Concepts Learned

- display: grid
- grid-template-columns
- grid-template-areas
- grid-area
- gap
- fr units
- Responsive Design
- Media Queries

## Folder Structure

- gallery.html
- product-grid.html
- dashboard.html
- style.css
- README.md

## Learning Outcome

Learned how to create responsive layouts using CSS Grid and organize content into rows and columns.
